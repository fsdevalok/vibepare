# Vibe Pare

A free random chat website — talk to strangers from your country.

## What it does
- No signup needed
- Enter name, country, gender
- Get matched with opposite gender first, then same gender
- Real-time text chat with emojis

## How to use
1. Visit vibepare.chat
2. Enter your name, country, gender
3. Click "Start Chat"
4. Talk!

## Tech used
- HTML, CSS, JavaScript
- Supabase (database + realtime)
- Vercel (hosting)
